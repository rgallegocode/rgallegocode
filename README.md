## Featured projects

### Tokenized bonds on Canton

Backend and blockchain implementation for a digital-bond platform built with Go, Daml and Canton. Includes a Dockerized multi-participant network, ledger API integration, Nginx frontend and Playwright end-to-end tests.

<a href="https://github.com/JavierStark/Project-CantonDaml-IoBuilders-UMA"><img src="https://img.shields.io/badge/Project-Canton%20%2F%20Daml-161B22?style=flat-square&logo=github" alt="Canton project" /></a>

### Cava Bot

Python Telegram bot that combines financial news, market data and Gemini-based summarization into a scheduled daily briefing, automated with GitHub Actions and cron without a dedicated server.

<a href="https://github.com/rgallegocode/cava-bot"><img src="https://img.shields.io/badge/Project-Cava%20Bot-161B22?style=flat-square&logo=github" alt="Cava Bot project" /></a>

### Bancosol Campañas

Java/Spring MVC university application for managing food-collection campaigns. I implemented the Captain module, authenticated-user filtering and role-based access control with Spring Security and JWT.

<a href="https://github.com/rgallegocode/Bancosol"><img src="https://img.shields.io/badge/Project-Bancosol-161B22?style=flat-square&logo=github" alt="Bancosol project" /></a>
